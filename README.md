# Wildlife Neighbours Community Display

Low-fidelity public touchscreen prototype for a community wildlife project.

## Open in VS Code

1. Open this folder in VS Code.
2. Open `index.html` with Live Server, or double-click it for a simple preview.
3. The bundled QR code links directly to `https://fencepost-app.vercel.app/` and works without an external QR-image service.

## Pages

- `index.html` — community display home
- `stories.html` — Story Time
- `animals.html` — Meet the Animals
- `quiz.html` — Footprint Quiz
- `sounds.html` — Animal Sounds

The `assets/sounds` folder contains three local non-verbal prototype clues: possum roof movement, frog croak, and bird call.

All pages use the shared `styles.css` and `app.js` files.
